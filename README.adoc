== curriculum.yaml ist die einzige Strukturwahrheit

Themenzuschnitt, Umfang in Unterrichtseinheiten, Block, Unterrichtsnummer,
Jahrgangszuordnung und Voraussetzungen stehen *ausschliesslich* in
`curriculum.yaml`. Eine Lernressource traegt ausser ihrer `:topic-id:` keine
Strukturangabe.

[source,adoc]
----
= Branching in git
:topic-id: git-branching
----

Die Dateipfade werden aus der ID abgeleitet, nicht eingetragen:
`modules/<topic-id>/index.adoc`.

WARNING: Sobald UE-Zahlen, Blockangaben oder Voraussetzungen zusaetzlich im
AsciiDoc auftauchen, gibt es zwei Wahrheiten. Die Pruefung meldet solche
Attribute als Fehler.

Alles Abgeleitete — Mindmap, Website-Navigation, UE-Uebersicht und
Fragenkatalog-Tags — wird erzeugt und nicht von Hand gepflegt.

== Pruefen und bauen

[source,bash]
----
python3 -m venv .venv && source .venv/bin/activate
pip install -r tools/requirements.txt

python tools/check-curriculum.py     # Struktur- und Modulpruefungen
----

Details zu den Werkzeugen: `tools/README.adoc`.

== Quellen und Rechte

Bilder tragen beim Einfuegen ihre Herkunft: `own`, `free` (mit Lizenzname und
Quelladresse) oder `unclear`. Der Job `rights-check` meldet `unclear` sichtbar,
verhindert die Veroeffentlichung aber nicht.

Das Manz-Schulbuch bleibt inhaltliche Quelle. Uebernommen werden nur Inhalte in
eigener Formulierung und eigener Gliederung — keine Abbildungen, keine
Seitenkopien, keine Weitergabe der PDF-Kapitel, auch nicht digital an einen
abgegrenzten Kurs.

== Uebungs- und Pruefungsangaben

[cols="1,2,2",options="header"]
|===
| |Uebung |Pruefung

|Sichtbarkeit
|public
|privat

|Ort
|`htl-leonding-example/jg03-syp-<topic-id>`
|Classroom-Organisation des Schuljahres

|Begruendung
|Loesungen duerfen bekannt sein; der Nachweis ist die muendliche Pruefung
|die Angabe ist wertlos, wenn sie vorab lesbar ist

|Wiederverwendung
|ueber Jahre
|keine — Angaben werden jaehrlich geaendert
|===

Nach der Durchfuehrung kann eine Pruefungsangabe oeffentlich werden und als
`<jahr>-exam-<thema>` ins Archiv wandern; ab dann ist sie Lernmaterial.

Die Zuordnung eines Moduls zu seiner Uebungsangabe steht als
`assignment_template` in `curriculum.yaml` — nur dadurch kann die erzeugte
Navigation sie verlinken.
